## 可选：运行 C 自测

每个 .c 都有自己的 main，**一次只编译一个文件**。不要把 8 个文件一起链接，也不要在自测时定义 NDEBUG。

在 Visual Studio 开发者终端进入 c 文件夹后运行：

~~~text
cl /std:c11 /utf-8 /W4 /D_CRT_SECURE_NO_WARNINGS 01_linear.c
01_linear.exe
~~~

将文件名换成其他章节即可。具体说明见 [源码说明](c/README.md)，测试环境和检查范围见 [验证说明](c/验证说明.md)。8 个程序已使用 MSVC C11、/W4 /WX 和 AddressSanitizer 编译并通过自测；GCC/Clang 命令仅作为使用指引，未在本环境实际执行。

## 可选：修改后重新生成

阅读资料不需要 Node.js。只有修改 notes.md 后需要重建网页与 Notebook 时，才需要安装 Node.js。

在仓库根目录的 PowerShell 中运行：

~~~powershell
node scripts/build.mjs
~~~

这会更新 index.html 与 ds408-notes.ipynb。要同时把 c 文件夹打成最新源码 ZIP，运行：

~~~powershell
& ./scripts/rebuild.ps1
~~~

笔记内代码与 c 文件夹里的独立程序分别维护。修改算法时需要同步修改两处，重新运行相应章节自测，再重建文件。
